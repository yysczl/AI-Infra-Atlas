## 一个位置如何读取其他位置

上一节得到的输入可以写成矩阵 X：每一行对应一个 token 的表示。Attention 让某个位置根据当前内容，对允许读取的位置分配权重，再组合这些位置的信息。

这里先看一个注意力头，省略 batch 维。设有 3 个位置，每个输入向量有 4 个数，即 X 的形状为 `[3, 4]`。模型通过三组学到的投影参数得到 Q、K、V：

| 运算 | 参数形状 | 输出形状 | 用途 |
| --- | --- | --- | --- |
| Q = X × Wq | `[4, 2]` | `[3, 2]` | 当前位置用什么信息查询 |
| K = X × Wk | `[4, 2]` | `[3, 2]` | 每个位置用于匹配的信息 |
| V = X × Wv | `[4, 2]` | `[3, 2]` | 按权重组合的信息 |

Q、K、V 都是数值向量。查询、匹配这些说法帮助解释角色，但不要将它们理解为人工设置的关键词或检索数据库。

## 顺着形状算一遍

```atlas-demo
attention
```

Q 的每一行与 K 的每一行做点积。矩阵写法为 `Q × Kᵀ`，形状从 `[3, 2] × [2, 3]` 变成 `[3, 3]`。其中第 i 行第 j 列表示位置 i 与位置 j 的匹配分数。

接下来分数除以 `sqrt(d_k)`；此处 `d_k = 2`。这个缩放用于控制点积随维度增长的尺度。再对不允许访问的位置加掩码，并对每一行做 softmax。最终得到权重 A，形状仍是 `[3, 3]`，每行的权重和为 1。

最后 `A × V` 的形状是 `[3, 3] × [3, 2] = [3, 2]`。**输出的每一行是该行权重对所有允许位置的 V 做的加权和。**

## 只算一行，看到具体数值

取某个查询 `q = [1, 0]`，允许读取的两个 key 是 `[1, 0]`、`[0, 1]`，对应 value 是 `[2, 0]`、`[0, 4]`。这是手工构造的数值例子，不是训练后的模型参数。

点积分数为 `[1, 0]`，除以 `sqrt(2)` 后约为 `[0.7071, 0]`。做 softmax 后约为 `[0.6698, 0.3302]`，输出因此约为 `[1.3395, 1.3210]`。

下面只用 Python 标准库复核。减去最大值不会改变 softmax 的结果，但能减少指数计算溢出的风险。

```python
import math
q = [1.0, 0.0]
keys = [[1.0, 0.0], [0.0, 1.0]]
values = [[2.0, 0.0], [0.0, 4.0]]
scores = [sum(a * b for a, b in zip(q, k)) / math.sqrt(2) for k in keys]
weights = [math.exp(s - max(scores)) for s in scores]
weights = [w / sum(weights) for w in weights]
output = [sum(w * v[j] for w, v in zip(weights, values)) for j in range(2)]
print([round(w, 4) for w in weights])
print([round(x, 4) for x in output])
```

## 为什么要遮住未来位置

在自回归模型里，位置 i 的表示用于预测后面的 token。如果它能直接读取未来 token，训练时就会获得生成时拿不到的信息。因果掩码使位置 i 只读取到当前位置及之前的位置。

三位置的允许关系如下，行是查询位置、列是被读取位置：

| 查询位置 | 位置 0 | 位置 1 | 位置 2 |
| --- | --- | --- | --- |
| 0 | 允许 | 遮住 | 遮住 |
| 1 | 允许 | 允许 | 遮住 |
| 2 | 允许 | 允许 | 允许 |

常见实现将被遮位置的分数设为负无穷，softmax 后对应权重为 0。不要在 softmax 之后简单清零而忘记权重归一化；也要避免一整行都被遮住而产生无效数值。补齐掩码与因果掩码解决的问题不同。

## 从单头到模型中的 Attention

多头注意力将表示分成多个查询头分别计算，再组合输出。模型还包含输出投影、残差连接、归一化、前馈网络及位置信息等部分；Attention 并不是整个 Transformer。

普通 MHA 中查询头与 KV 头数量相同。GQA 让多个查询头共享一组 K/V；这会改变 KV Cache 的容量计算，后面的课程将单独使用 KV 头数。这里的单头例子用于理解计算，不假设所有模型都使用同一种结构。

## 练习：检查一处维度错误

如果 Q 为 `[5, 8]`，K 为 `[5, 8]`，V 为 `[5, 6]`，可以直接计算 `Q × K` 吗？正确输出形状是什么？

```atlas-answer
不能直接相乘：内维 8 和 5 不匹配。应计算 `Q × Kᵀ` 得到 `[5, 5]` 的分数，再用归一化权重乘 V，输出 `[5, 6]`。注意 value 维度可以与 key 维度不同。
```
