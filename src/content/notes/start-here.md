# 如何使用这座学习站

第一次使用，可以从首页的“查看学习路径”开始。已经有明确问题时，也可以直接进入对应领域或实验，不必先读完全部课程。

## 完成一次实验

1. **明确要验证的问题**：例如“上下文变长后，吞吐量和时延怎样变化？”
2. **补齐前置概念**：打开实验关联的主题，确认理解本实验涉及的术语。
3. **检查实验环境**：逐项核对硬件、软件、权限和费用提醒，先执行环境检查命令。
4. **按顺序操作**：复制每一步的命令或配置，不要随意跳过；每一步都对照“预期结果”检查。
5. **遇到问题先定位**：查看步骤下方的提示和实验末尾的“故障排查”，保留完整报错，不用反复重试同一条失败命令。
6. **保存结果并清理**：下载实验记录模板，填写实际环境、命令、原始数据和结论，再按“清理与注意事项”停止进程、删除不再需要的文件或云端资源。

## 按你的目标选择入口

### 刚开始学：沿学习路径前进

从系统基础和 GPU 开始，再进入训练、推理和工程化主题。每学完一个主题可以勾选进度，下次打开网站时继续。

### 解决具体问题：查知识地图和实验

按问题进入对应领域，先读核心问题与概念，再选择相关实验。资源库可以按领域、类型和难度筛选，收藏常用资料。

### 复盘与积累：写学习笔记

在“我的笔记”中记录实际执行的命令、软件版本、关键日志、指标和未解决的问题。内置指南也可以作为新笔记的模板；单篇笔记可导出为 Markdown。

> 学习进度、收藏、实验勾选和浏览器内新建的笔记只保存在当前浏览器。换设备或清理浏览器数据前，请先在“设置与备份”页导出学习数据。
