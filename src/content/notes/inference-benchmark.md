# 推理压测报告

## 一句话结论

在 **明确硬件、模型与 SLO** 的前提下，系统在何种负载下达到多少 goodput；主要瓶颈是什么。

## 指标定义

- **TTFT**：从请求发起到首个 token 返回。
- **TPOT**：首 token 之后，输出 token 的平均间隔。
- **E2E latency**：完整请求的端到端延迟。
- **Throughput**：单位时间完成的请求数或 token 数。
- **Goodput**：满足预先定义 SLO 的有效吞吐。

## 结果

至少报告 P50、P95、P99、错误率和请求级原始数据。保留吞吐随负载增长的完整曲线，不只选择一个最漂亮的点。

## 分析

1. 性能拐点在哪个负载出现？
2. 时间花在哪一段队列或执行阶段？
3. 改变优化项时，模型语义和质量是否保持一致？
4. 结论对输入长度、输出长度和流量突发是否敏感？
